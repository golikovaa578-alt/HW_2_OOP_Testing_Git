# HW_2_OOP_Testing_Git

Проект по объектно-ориентированному программированию на Python. Реализует систему классов для управления кулинарными рецептами, ингредиентами и списком покупок.

## Описание проекта

Проект состоит из четырёх классов:

**Ingredient** — базовая единица рецепта. Хранит название продукта, его количество и единицу измерения (г, кг, мл, шт). Количество валидируется через `@property` — не может быть отрицательным или нулевым.

**Recipe** — рецепт одного блюда. Объединяет название блюда с набором ингредиентов. Умеет добавлять ингредиенты без дубликатов, масштабировать порции и возвращать количество уникальных ингредиентов.

**ShoppingList** — список покупок. Собирает ингредиенты из нескольких рецептов, автоматически суммируя одинаковые продукты. Поддерживает добавление и удаление рецептов, а также объединение двух списков.

**DietaryRecipe** — наследник Recipe. Добавляет диетическую категорию блюда (например, "веган", "без глютена", "кето").

## Установка и запуск

Установить зависимости:

Запуск notebook:

Запуск тестов:
pytest test_recipes.py -v

## Примеры использования

```python
from recipes import Ingredient, Recipe, ShoppingList

# Создание ингредиентов
мука = Ingredient("Мука", 500, "г")
сахар = Ingredient("Сахар", 200, "г")

# Создание рецепта
рецепт = Recipe("Пирог")
рецепт.add_ingredient(мука)
рецепт.add_ingredient(сахар)

# Масштабирование на 2 порции
большой = рецепт.scale(2)

# Список покупок
список = ShoppingList()
список.add_recipe(рецепт, 1)
print(список.get_list())
```

## Тестирование

Тесты написаны с использованием библиотеки `pytest` и покрывают:
- Создание и валидацию ингредиентов
- Добавление ингредиентов без дубликатов
- Масштабирование рецептов
- Работу списка покупок
- Объединение списков покупок
